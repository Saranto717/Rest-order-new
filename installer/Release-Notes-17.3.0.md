## Εγκατάσταση Windows χωρίς κώδικα ή εντολές

Κατέβασε το **RestaurantOrders-Setup-17.3.0-win-x64.exe** από τα Assets και εκτέλεσέ το στον κεντρικό υπολογιστή Windows x64 του καταστήματος.

- Περιλαμβάνει το .NET runtime και εγκαθιστά την εφαρμογή ως υπηρεσία που ξεκινά αυτόματα με τα Windows.
- Δημιουργεί συντόμευση για τη σελίδα `http://localhost:5080/`.
- Διατηρεί βάση/ρυθμίσεις στο `C:\ProgramData\RestaurantOrders`, υποστηρίζει εισαγωγή υπάρχουσας βάσης και κρατά αντίγραφο πριν από αναβάθμιση.
- Τα κινητά/tablets χρησιμοποιούν μόνο browser στο ίδιο τοπικό δίκτυο.
- Οι λειτουργίες POS Mellon, Viva, epay και EDPS διατηρούνται από την ολοκληρωμένη v17.2.

Το συγκεκριμένο binary προωθείται από επιτυχημένη εκτέλεση Windows που πέρασε 170 regression assertions και πραγματικές δοκιμές εγκατάστασης, αναβάθμισης, διατήρησης δεδομένων και απεγκατάστασης. Πριν από τη δημοσίευση ελέγχεται το SHA256 και ότι τα αρχεία εφαρμογής/συσκευασίας συμφωνούν με την ελεγμένη έκδοση.

Ο installer δεν είναι ψηφιακά υπογεγραμμένος. Περιλαμβάνονται αρχείο SHA256 και οδηγίες πελάτη. Για λήψη των δημόσιων release assets δεν απαιτείται σύνδεση στο GitHub.
