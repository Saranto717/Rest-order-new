# Εγκατάσταση πελάτη με Setup.exe

Το installer προορίζεται για τον κεντρικό υπολογιστή Windows x64 του καταστήματος. Τα κινητά και τα tablets χρησιμοποιούν μόνο browser στο ίδιο τοπικό δίκτυο.

## Λήψη έτοιμου installer

**Για τον πελάτη:** κατέβασε απευθείας το [RestaurantOrders Setup 17.3.0 για Windows x64](https://github.com/Saranto717/Rest-order-new/releases/download/v17.3.0/RestaurantOrders-Setup-17.3.0-win-x64.exe) ή άνοιξε τη [σελίδα της έκδοσης](https://github.com/Saranto717/Rest-order-new/releases/tag/v17.3.0). Η δημόσια λήψη δεν απαιτεί λογαριασμό GitHub. Εκτέλεσε το `.exe`· δεν χρειάζεται αποσυμπίεση ή πηγαίος κώδικας.

Η έκδοση προωθεί ακριβώς το ελεγμένο binary από επιτυχημένο Windows build, επαληθεύοντας το SHA256 και την ταύτιση των αρχείων εφαρμογής/συσκευασίας.

### Εναλλακτική λήψη development artifacts

1. Άνοιξε το [GitHub Actions: Windows customer installer](https://github.com/Saranto717/Rest-order-new/actions/workflows/windows-installer.yml).
2. Επίλεξε την τελευταία **επιτυχημένη** εκτέλεση. Η εκτέλεση περιλαμβάνει build, regression tests και πραγματική εγκατάσταση/αναβάθμιση/απεγκατάσταση σε Windows runner.
3. Κατέβασε το artifact **RestaurantOrders-Setup-win-x64** στο κάτω μέρος της σελίδας. Το GitHub απαιτεί σύνδεση για τη λήψη artifacts.
4. Αποσυμπίεσε το ZIP και δώσε στον πελάτη το `RestaurantOrders-Setup-17.3.0-win-x64.exe` και τις οδηγίες. Περιλαμβάνεται και αρχείο SHA256.

Δεν χρειάζεται να δώσεις τον κώδικα, το SDK ή τα αρχεία του repository στον πελάτη. Τα artifacts διατηρούνται για 90 ημέρες· κράτησε το installer για τις εγκαταστάσεις σου. Το workflow εκτελείται αυτόματα σε σχετικές αλλαγές στο `main` και μπορεί να ξεκινήσει και με **Run workflow**.

## Τι κάνει το Setup

- Εγκαθιστά τη self-contained εφαρμογή .NET 8 στο `C:\Program Files\RestaurantOrders`.
- Δημιουργεί την υπηρεσία `RestaurantOrders`, με αυτόματη καθυστερημένη εκκίνηση και επανεκκίνηση σε αστοχία, υπό τον λογαριασμό Network Service.
- Αποθηκεύει SQLite, ρυθμίσεις και κλειδιά σύνδεσης στο `C:\ProgramData\RestaurantOrders`, χωριστά από τα εκτελέσιμα.
- Προσφέρει προαιρετική εισαγωγή παλιάς `restaurant.db` στην πρώτη εγκατάσταση. Χρησιμοποιείται το SQLite online backup API, ώστε να περιλαμβάνονται τα committed δεδομένα από το WAL. Η υπάρχουσα εγκατεστημένη βάση δεν αντικαθίσταται από εισαγωγή.
- Σταματά την υπηρεσία πριν από την αντιγραφή αρχείων αναβάθμισης και δημιουργεί αντίγραφο της βάσης, των ρυθμίσεων και των κλειδιών στον υποφάκελο `Backups` πριν από την επόμενη εκκίνηση.
- Δημιουργεί συντομεύσεις για `http://localhost:5080/` και σελίδα με τις τοπικές διευθύνσεις για κινητά/tablets.
- Επιτρέπει εισερχόμενη TCP 5080 μόνο από το τοπικό υποδίκτυο, στο ιδιωτικό προφίλ του Windows Firewall.
- Ελέγχει ότι η υπηρεσία απαντά πριν αναφέρει επιτυχία. Η θύρα 5080 πρέπει να είναι διαθέσιμη.
- Κατά την απεγκατάσταση αφαιρεί υπηρεσία/κανόνα firewall και διατηρεί τα δεδομένα.

Ο πελάτης ακολουθεί τον οδηγό εγκατάστασης, εγκρίνει το αίτημα δικαιωμάτων Windows και ανοίγει τη συντόμευση. Δεν εκτελεί εντολές και δεν κρατά ανοιχτό τερματικό.

Στη νέα βάση ο αρχικός διαχειριστής έχει PIN `1234`, όπως στην υφιστάμενη εφαρμογή. Μετά την πρώτη σύνδεση αλλάζει το PIN και συμπληρώνει τις ρυθμίσεις καταστήματος, Parochos, POS και εκτυπωτών. Σε εισαγωγή/αναβάθμιση διατηρούνται οι υπάρχοντες χρήστες.

## Ρυθμίσεις και διάγνωση

- Η εγκατεστημένη εφαρμογή ενεργοποιεί την ξεχωριστή διαχείριση δεδομένων με `Installation:Enabled=true`. Η συνηθισμένη εκτέλεση ανάπτυξης διατηρεί την προηγούμενη συμπεριφορά της.
- Το `appsettings.Installed.json` δημιουργείται μόνο αν δεν υπάρχει και διατηρείται στις αναβαθμίσεις. Η εγκατάσταση χρησιμοποιεί `Urls: http://0.0.0.0:5080`.
- Τα επίμονα κλειδιά Data Protection προστατεύονται με Windows DPAPI και ο φάκελος δεδομένων δίνει δικαίωμα τροποποίησης μόνο σε Administrators, SYSTEM και Network Service.
- Τα σφάλματα εγκατάστασης γράφονται στο `C:\ProgramData\RestaurantOrders\installer-error.log`. Υπάρχει επίσης `installer.log` και το Windows Application event log με πηγή `RestaurantOrders`.
- Δεν απαιτείται development HTTPS certificate. Η αρχική έκδοση εγκατάστασης εξυπηρετεί το τοπικό δίκτυο με HTTP. Το αυτόματο άνοιγμα της σελίδας δεν σημαίνει ότι ο υπολογιστής μπορεί να κλείσει: η υπηρεσία πρέπει να παραμένει ενεργή για τις υπόλοιπες συσκευές.
- Το installer δεν υπογράφεται ψηφιακά, επειδή δεν έχει δοθεί πιστοποιητικό υπογραφής εκδότη. Τα Windows μπορεί να εμφανίσουν προειδοποίηση άγνωστου εκδότη.

## Παραγωγή installer από τον προγραμματιστή

Σε Windows με .NET SDK 8 και Inno Setup 6:

```powershell
.\installer\windows\Build-Installer.ps1
```

Αυτό είναι εργαλείο ανάπτυξης. Ο πελάτης παραλαμβάνει μόνο το παραγόμενο `Setup.exe`. Το publish ελέγχεται ώστε να μην περιλαμβάνει `.cs`, `.razor`, `.csproj`, `.sln`, `.pdb`, βάσεις ή logs.

Οι connectors και οι ροές πληρωμής της v17.2 δεν τροποποιούνται από την προσθήκη εγκατάστασης.
