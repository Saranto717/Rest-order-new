RESTAURANTORDERS — ΧΡΗΣΗ ΑΠΟ ANDROID ΚΑΙ IPHONE ΣΤΟ ΙΔΙΟ WI-FI

ΤΙ ΥΠΟΣΤΗΡΙΖΕΤΑΙ
- Το RestaurantOrders συνεχίζει να τρέχει στον υπολογιστή Windows του καταστήματος.
- Τα κινητά Android και iPhone ανοίγουν τη web εφαρμογή από Chrome/Safari μέσω του ίδιου τοπικού Wi-Fi.
- Η βάση δεδομένων και οι εκτυπωτές παραμένουν στον υπολογιστή του καταστήματος.
- Το κινητό πρέπει να έχει πρόσβαση στο ίδιο τοπικό δίκτυο. Δεν απαιτείται δημόσιο Internet για την τοπική σύνδεση.

ΒΗΜΑ 1 — ΕΛΕΓΞΕ ΤΟ ΔΙΚΤΥΟ
1. Σύνδεσε τον υπολογιστή του RestaurantOrders και τα κινητά στο ίδιο Wi-Fi/router.
2. Το δίκτυο Windows πρέπει να έχει χαρακτηριστεί Private/Ιδιωτικό, μόνο εφόσον είναι έμπιστο δίκτυο του καταστήματος.
3. Μην επιτρέψεις θύρα 5000 σε Public/Δημόσια δίκτυα και μη ρυθμίσεις port forwarding στον router.

ΒΗΜΑ 2 — ΒΡΕΣ ΤΗ ΔΙΕΥΘΥΝΣΗ ΤΟΥ ΥΠΟΛΟΓΙΣΤΗ
1. Στον υπολογιστή του καταστήματος, άνοιξε Command Prompt ή PowerShell.
2. Εκτέλεσε: ipconfig
3. Στον ενεργό προσαρμογέα Wi-Fi ή Ethernet, βρες το IPv4 Address/Διεύθυνση IPv4, π.χ. 192.168.1.50.
   Χρησιμοποίησε την πραγματική διεύθυνση που εμφανίζεται στον υπολογιστή σου· το παραπάνω είναι μόνο παράδειγμα.

ΒΗΜΑ 3 — ΑΝΟΙΞΕ ΤΗΝ ΕΦΑΡΜΟΓΗ ΣΤΟ ΚΙΝΗΤΟ
- Android: άνοιξε Chrome και γράψε http://IP-ΤΟΥ-ΥΠΟΛΟΓΙΣΤΗ:5000
- iPhone: άνοιξε Safari και γράψε http://IP-ΤΟΥ-ΥΠΟΛΟΓΙΣΤΗ:5000
Παράδειγμα μόνο: http://192.168.1.50:5000

Για συντόμευση στην αρχική οθόνη:
- Android/Chrome: με ανοιχτή την εφαρμογή, άνοιξε το μενού ⋮ και επίλεξε «Προσθήκη στην αρχική οθόνη» ή «Install app», αν εμφανίζεται.
- iPhone/Safari: πάτησε Share/Κοινή χρήση και μετά «Add to Home Screen/Προσθήκη στην οθόνη Αφετηρίας».

ΣΗΜΑΝΤΙΚΟ ΓΙΑ ΤΗ ΣΥΝΤΟΜΕΥΣΗ
Η τοπική έκδοση λειτουργεί μέσω HTTP στο LAN. Η εγκατάσταση ως πλήρες PWA με όλες τις δυνατότητες εγκατάστασης του browser απαιτεί HTTPS με πιστοποιητικό που εμπιστεύεται το κινητό. Η συντόμευση στην αρχική οθόνη δεν κάνει την εφαρμογή offline: ο υπολογιστής του καταστήματος και το Wi-Fi πρέπει να είναι διαθέσιμα.

ΑΝ ΔΕΝ ΑΝΟΙΓΕΙ
1. Έλεγξε ότι η υπηρεσία RestaurantOrders εκτελείται (Get-Service RestaurantOrders).
2. Δοκίμασε πρώτα στον ίδιο τον υπολογιστή: http://localhost:5000
3. Έλεγξε ότι κινητό και υπολογιστής είναι στο ίδιο Wi-Fi και όχι σε guest network/client isolation.
4. Στον υπολογιστή, το Windows Firewall επιτρέπει TCP 5000 μόνο σε Private δίκτυο και τοπικό υποδίκτυο. Αν το δίκτυο είναι αξιόπιστο αλλά έχει οριστεί Public, άλλαξε το προφίλ σε Private από τις ρυθμίσεις Windows.
5. Αν η IP του υπολογιστή αλλάξει, ενημέρωσε τη διεύθυνση στο κινητό. Για σταθερή διεύθυνση, προτίμησε DHCP reservation στον router.
6. Μη ρυθμίσεις port forwarding και μην εκθέσεις τη θύρα 5000 στο Internet.

ΠΡΟΣΟΧΗ
Η τοπική πρόσβαση χρησιμοποιεί HTTP και προορίζεται μόνο για έμπιστο εσωτερικό δίκτυο του καταστήματος. Για δίκτυο στο οποίο έχουν πρόσβαση μη έμπιστοι χρήστες, χρειάζεται πρόσθετη ασφαλής ρύθμιση HTTPS και περιορισμός πρόσβασης.
