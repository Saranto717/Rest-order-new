# Κατάλογος: μετονομασία και ενεργοποίηση κατηγοριών

- Η διαχείριση κατηγοριών επιτρέπει πλέον μετονομασία χωρίς διαγραφή/δημιουργία νέας εγγραφής.
- Οι κατηγορίες έχουν κατάσταση Ενεργή/Ανενεργή. Η απενεργοποίηση δεν διαγράφει κατηγορία, προϊόντα, extras ή αντιστοιχίσεις εκτυπωτών.
- Η οθόνη λήψης παραγγελίας εμφανίζει μόνο ενεργές κατηγορίες. Με επανενεργοποίηση η κατηγορία εμφανίζεται ξανά.
- Τα ήδη υπάρχοντα κουμπιά «Επεξεργασία» στα προϊόντα και στα extras επιτρέπουν επεξεργασία ονόματος (και των υπόλοιπων πεδίων που υποστηρίζονται από την κάθε σελίδα).
- Κατά την εκκίνηση, η συμβατότητα βάσης προσθέτει τη στήλη `MenuCategories.IsActive` σε υπάρχον `restaurant.db` με προεπιλογή ενεργή. Δεν απαιτείται διαγραφή βάσης.
