RESTAURANTORDERS — ΕΚΔΟΣΗ ΓΙΑ ΚΙΝΗΤΑ (ANDROID + IOS)

Τι περιλαμβάνει αυτή η αλλαγή:
- Το build δημοσίευσης ρυθμίζει το Kestrel να ακούει στη θύρα 5000 από το τοπικό δίκτυο (0.0.0.0).
- Το script εγκατάστασης δημιουργεί κανόνα Windows Firewall για TCP 5000 μόνο σε Private προφίλ και LocalSubnet.
- Η σελίδα τραπεζιών ανοίγει με απλό tap/click αντί για διπλό πάτημα.
- Προστέθηκαν responsive κανόνες για οθόνες κινητών, πιο μεγάλοι στόχοι αφής, οριζόντια κύλιση κατηγοριών και διάταξη παραγγελίας σε μία στήλη.
- Προστέθηκαν metadata, manifest και εικονίδια αρχικής οθόνης για Android/iOS.
- Το μοντέλο παραμένει Blazor Interactive Server: η εφαρμογή και η βάση τρέχουν στον υπολογιστή του καταστήματος, άρα το κινητό χρειάζεται σύνδεση στο Wi-Fi και ο server πρέπει να μένει ενεργός.

Πώς το δοκιμάζεις:
1. Άνοιξε Source\RestaurantOrders.sln στο Visual Studio 2022 και κάνε Build → Build Solution.
2. Εκτέλεσε το Build-Release.ps1 από τον φάκελο του kit.
3. Μετά το επιτυχές publish, πέρασε το RestaurantOrders_Customer_Update.zip στον υπολογιστή του καταστήματος και τρέξε το Install-RestaurantOrders.ps1 ως Administrator.
4. Μετά την εγκατάσταση, χρησιμοποίησε τη διεύθυνση http://IP-ΤΟΥ-SERVER:5000 από κινητό στο ίδιο Wi-Fi.
5. Δοκίμασε πρώτα επιλογή τραπεζιού, προσθήκη προϊόντος/extra και αποστολή μίας δοκιμαστικής παραγγελίας.

Περιορισμοί και ασφάλεια:
- Τοπική σύνδεση HTTP, όχι δημόσια υπηρεσία. Μην κάνεις port forwarding στον router και μην εκθέσεις τη θύρα 5000 στο Internet.
- Ο κανόνας firewall αφορά έμπιστο ιδιωτικό δίκτυο και LocalSubnet. Βεβαιώσου ότι τα κινητά δεν είναι σε Guest Wi-Fi με client isolation.
- Η προσθήκη shortcut στην αρχική οθόνη μπορεί να είναι διαθέσιμη από Chrome/Safari, ανάλογα με συσκευή/έκδοση. Πλήρης εγκατάσταση PWA απαιτεί HTTPS με πιστοποιητικό εμπιστευμένο από το κινητό.
- Η εφαρμογή δεν είναι offline· ο Windows server και η σύνδεση Wi-Fi πρέπει να είναι διαθέσιμα.
- Δεν έγινε compile σε αυτό το περιβάλλον επειδή δεν είναι εγκατεστημένο το .NET SDK. Απαραίτητο το Build & test στον developer PC πριν τη διάθεση στον πελάτη.
