# Διόρθωση Mellon Redeem — v17.1

Για εγκατάσταση που έχει ήδη τον κώδικα v17:

1. Σταμάτησε την εφαρμογή.
2. Αντικατάστησε μόνο το αρχείο `RestaurantOrders_Mobile_WiFi_Source/Source/Services/MellonWebEcrService.cs` με το αντίστοιχο του ZIP.
3. Κάνε rebuild / publish και εκκίνησε ξανά την εφαρμογή.
4. Δοκίμασε ξανά το Redeem για το Mellon POS.

Δεν χρειάζεται αλλαγή στη βάση ή στα αποθηκευμένα POS. Οι connectors epay/EDPS δεν τροποποιούνται.

Το αίτημα στέλνει πλέον τα ακριβή ονόματα JSON `Type` και `Code`, όπως απαιτεί το API, αντί για `type` και `code`.

Έγινε επιτυχές build και πέρασαν 83 regression assertions με προσομοιωμένο API. Η δοκιμή με αυστηρή διάκριση πεζών/κεφαλαίων απέτυχε πριν από τη διόρθωση και πέρασε μετά. Δεν έγινε επικοινωνία με πραγματικό POS.
